# Kiki

Kiki is an extension focusing on icon themes with consistency and broad language coverage.  Kiki also includes a color theme.

## Features

- Clear, readable file icons
- Consistent visual style 
- Strong support for modern, legacy, and niche languages
- Color themes

## Usage

- Open the Command Palette
- Run Preferences: File Icon Theme
- Select Kiki

## Feedback

- Missing a file type or language? Open an issue.
